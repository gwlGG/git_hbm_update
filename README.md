# git_hbm_update
部分软件暂不兼容鸿蒙 OS。如使用鸿蒙设备，请先开通 Windows 虚拟机，再在虚拟机中的蓝区 Windows 系统内完成后续软件的安装与配置。
1.开通虚拟机：在鸿蒙 OS 中，通过“端到端”中的“澳易”软件开通 Windows 虚拟机。
2.等待安装与更新：安装及更新过程需要一定时间，请耐心等待，待更新成功后再进行下一步。
3.完成域账号验证：更新成功后，在内网环境下按提示输入域账号和密码，完成验证。
4.切换后使用蓝区 Windows：上述操作完成后，切换至 huaweiguest，即可在虚拟机中使用蓝区 Windows 系统，并按后续章节安装所需软件。
